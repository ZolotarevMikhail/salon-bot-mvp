# Салон красоты — телеграм-бот (MVP)

> Универсальный бот для салона красоты: ответы клиенткам, запись, передача
> диалога администратору. Настройка под конкретный салон — в одном файле
> `knowledge.py`, без изменения кода. В этой версии данные демонстрационные.

Бот для клиентов студии: показывает услуги и цены, отвечает на частые вопросы,
принимает заявки на запись и соединяет с администратором.

> Сейчас внутри — **условные (выдуманные) данные** для демо.
> Настоящие данные студии потом просто вписываются в один файл `knowledge.py`.

---

## Что умеет бот (этап 1)

1. **Услуги и цены, мастера, акции, контакты** — по кнопкам меню.
2. **Ответы на частые вопросы** — бот узнаёт темы по словам: «больно ли»,
   «сколько держится», «можно ли беременным», «оплата картой» и т.д.
   Чего нет в базе — бот не выдумывает, а зовёт администратора.
3. **Запись** — клиент выбирает услугу, мастера, день и время; заявка уходит
   администратору в личку, бот подтверждает клиенту. Администратор вручную
   подтверждает запись — двойных броней не бывает.
4. **«Позвать администратора»** — вопрос клиента пересылается живому человеку
   вместе с историей диалога. Ответить можно прямо из Telegram: ответом
   (реплаем) на пересланное сообщение — бот передаст ответ клиенту.

Что будет позже (этапы 2–3): живое расписание из вашей системы, напоминания
накануне визита, возврат «уснувших» клиенток.

## Запуск у себя на компьютере (macOS) — 3 шага

### Шаг 1. Создать бота в Telegram (2 минуты, бесплатно)

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте имя (например, `MNE MANIC`) и имя-логин на латинице
   (например, `mne_manik_demo_bot` — должно оканчиваться на `bot`).
4. BotFather пришлёт **токен** — строку вида `1234567890:AA...`.
   Это «пропуск» бота, храните его в тайне.

### Шаг 2. Вписать токен и ID администратора

1. В папке бота откройте файл `.env.example`, скопируйте его и сохраните
   копию под именем `.env` (точка в начале имени важна).
2. Впишите в него две строки:
   ```
   BOT_TOKEN=токен от BotFather
   ADMIN_CHAT_ID=ваш_id
   ```
3. Своим ID узнать просто: запустите бота один раз (шаг 3), отправьте ему
   команду `/id` — он напишет ваш ID. Впишите его в `.env` и перезапустите бота.

### Шаг 3. Запустить

**Вариант А — просто:** двойной клик по файлу `run.command`.
Первый запуск установит библиотеку (пара минут), дальше — секунд.

**Вариант Б — из терминала:**
```bash
cd путь/к/mne-manik-bot
python3 -m pip install -r requirements.txt
python3 bot.py
```

Бот работает, пока открыто окно запуска. Закрыли окно — бот молчит
(в этом минус «бота дома»; для работы 24/7 нужен дешёвый арендованный
сервер — инструкция прилагается ниже).

### Проверка

1. Найдите бота в Telegram по имени-логину из шага 1.
2. `/start` → появится меню.
3. Попробуйте: «Услуги и цены» → «Записаться» → пройдите до подтверждения —
   заявка придёт вам же (если ADMIN_CHAT_ID — ваш ID).
4. «Позвать администратора» → напишите вопрос → с другого окна
   (или с телефона) ответьте **реплаем** на пересланное сообщение —
   ответ вернётся клиенту.

## Как менять данные студии (без программиста)

Все данные лежат в одном файле — **`knowledge.py`**, открывается любым
текстовым редактором:

| Что поменять | Где в файле |
|---|---|
| Название студии | `STUDIO_NAME` |
| Услуги и цены | список `SERVICES` |
| Мастера | список `MASTERS` |
| Акции | список `PROMOS` |
| Адрес, часы, телефон | блок `CONTACTS` |
| Ответы на частые вопросы | список `FAQ` (вопрос = `keywords`, ответ = `answer`) |

После правок перезапустите бота (закрыть окно `run.command` и открыть снова).
Если меняете `.env` — тоже нужен перезапуск.

## Работа 24/7 (когда решите выйти из демо)

Боту нужен постоянно работающий компьютер. Два пути:

**Путь 1 — свой компьютер.** Запускать `run.command` и не выключать машину.
Бесплатно, но бот живёт ровно столько, сколько работает компьютер.

**Путь 2 — арендованный сервер (~500–1000 ₽/мес).**
Подойдёт любой сервис с арендой простого сервера (VPS), например
Beget, Timeweb, Selectel. Порядок такой:
1. Арендуете минимальный сервер на Ubuntu (в панели сервиса — пара кликов).
2. Сервис пришлёт логин/пароль; подключиться можно с любого компьютера.
3. Копируете папку бота на сервер и запускаете теми же командами, что выше
   (Python и библиотека ставятся одной командой — пришлём точную памятку
   под конкретный сервис, когда выберете).
4. Бот работает 24/7, ваш компьютер можно выключать.

Выбор и оплата — за вами; поможем на каждом шаге.

## Безопасность

- Токен бота хранится в файле `.env` — **никогда не публикуйте его** и не
  отправляйте никому, кроме нас при настройке.
- Если токен случайно «утёк» — он отзывается в @BotFather командой
  `/revoke` и выдаётся новый.
